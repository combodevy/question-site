AI 文档导入流程
  1. 上传包含试题的 .txt / .md / .docx / .pdf 文件，或粘贴原始试题文本。
  2. 点击「生成 JSON 预览」，在 AI 弹窗中检查题库结构和题目内容。
  3. 确认无误后，再点击「导入预览 JSON 到题库」。

AI 识别文档生成题库

1️⃣ 上传包含试题的文档（支持 .txt / .md / .docx / .pdf）或直接在下方文本框粘贴试题原文。
2️⃣ 点击「AI 识别并导入」，系统会调用已配置的大模型自动抽取选择题 / 判断题并排版成题库 JSON，直接合并进当前题库。
